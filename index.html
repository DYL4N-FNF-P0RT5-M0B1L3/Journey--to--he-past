What it does

Uses the Internet Archive Wayback Machine APIs directly from your browser. It can find historical captures even when the original page no longer exists.

Open old versions

Every result links to the archived snapshot. Resources such as images, CSS, and scripts may be incomplete depending on how the original site was captured.

Privacy

This static page does not need your own server. Searches are sent to the Internet Archive because its public API performs the archive lookup.
